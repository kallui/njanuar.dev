## Feature Development & Collaboration

I developed front-end features using React and React Native, and worked on the backend using Node.js, Express, and TypeScript. Outside of feature development, I regularly addressed high-priority bugs, helped test fellow developers’ feature branches, reviewed pull requests, and wrote tests using Jest and Mocha.js to help maintain application quality.

## End-to-End Project

I had the opportunity to lead the end-to-end development of a project that involved changes across the full stack, including front-end updates, new backend API endpoints, and MySQL database queries. I planned the implementation, provided regular updates to the team, and guided the project from development to completion.
